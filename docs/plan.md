# Biomass Engineers Limited — Build Plan

Source spec: `../biomass-engineers-website-prompts.md` (Prompt A).

## Stack

- Next.js 16.2.4 (App Router, Turbopack default)
- React 19.2
- TypeScript 5
- Tailwind CSS v4 (`@theme inline` in globals.css)
- Framer Motion, React Hook Form, Zod, Resend, Anthropic SDK
- MDX for blog (`@next/mdx`, `gray-matter`)
- next-sitemap

## Next.js 16 notes (breaking from training data)

- `params` / `searchParams` are Promises — always `await`.
- `PageProps<'/route'>` / `LayoutProps<'/route'>` / `RouteContext<'/route'>` global helpers (generated by typegen).
- Turbopack default. No flag needed.
- `middleware` → `proxy` (not used here).
- `minimumCacheTTL` default 4h; `qualities: [75]`; `images.domains` deprecated → `remotePatterns`.
- React 19.2 canary inside App Router — `useEffectEvent`, `ViewTransition` available.

## Phases

1. **Foundation** — Tailwind v4 tokens, Google fonts (Syne + DM Sans), `app/layout.tsx`, `TopBar`, `Navbar` (mega-dropdown + mobile), `Footer`, homepage.
2. **Shared components** — `CallbackForm`, `FAQAccordion`, `CTAStrip`, `ServiceCard`, `BrandCard`, `CaseStudyCard`, `ReviewCard`, `BlogCard`, `ImagePlaceholder`, `StatsStrip`, `BenefitsList`, `ProcessSteps`, `Hero`. Shared page templates: `BrandPage`, `LocationPage`, `CaseStudyPage`, `ServicePage`.
3. **Service pages** (10) — installation, installation-process, servicing-and-maintenance, servicing-and-repair, commercial-service, engineer-services, servicing-cost, parts-and-spares, specification-system-design, district-heating, coded-welding.
4. **Brand hub + 6 brand pages** — Fröling, Hargassner, Herz, Heizomat, Binder, Windhager. Dynamic `[brand]` route + static `generateStaticParams`.
5. **Case studies** — hub + 6 studies via dynamic `[slug]`.
6. **Location pages** (22) — Devon/Cornwall/Somerset/Dorset/Bristol/Wiltshire/Hampshire. Shared `LocationPage` fed from `lib/locations.ts`. Generated unique content per city.
7. **Specialist pages** — Existing Boilers, RHI, Testimonials, FAQs, About/Our Team/Accreditations, Contact, Gallery, Privacy, Cookie Policy, /sitemap HTML page, Affiliate Companies.
8. **Blog** — 11 MDX posts under `content/blog/`, `/blog` index, `/blog/[slug]` route reading MDX at build.
9. **API routes** — `/api/contact` (Zod + Resend + honeypot), `/api/chat` (Anthropic streaming, claude-haiku-4-5, temp 0.4, max tokens 400). `ChatWidget` client component.
10. **SEO** — per-page metadata, LocalBusiness / Service / FAQPage / BlogPosting / Article JSON-LD, `next-sitemap` config, `robots.txt`.
11. **Polish** — mobile pass, a11y (focus rings, aria, keyboard), image placeholders, `npm run build` must pass.
